# Lesson 8 — Apply what you learned

Prerequisite: local course completed; deployment may be deferred. Outcome: transfer
the pattern to a small learner-authored flow and choose further study. Read
[quickstart](../references/quickstart.md) and the action references needed for their
chosen flow. Pause after each checkpoint.

## 8.1 — Describe the next flow

Ask for a small source-to-output goal, or offer adapting the sample nation flow
into a distinct learning output. Identify source, transformations, write behaviour
and environment settings together. Use an isolated learning project/copy if the
current project is shared. Activity: learner describes the flow in those terms.
Save their choice and pause; do not write their YAML yet.

## 8.2 — Author a small definition

Point to the closest existing pattern and relevant reference; for a sample-only
exercise, use the nation load/write pair as a model and choose distinct flowgroup,
action/view and output names to avoid collisions. Let the learner write it. If a
template already fits their real task, have them create its parameterized instance
rather than duplicating it. Activity: save the new definition and say ready.

## 8.3 — Verify and explain

Read the learner's attempt, give specific feedback and let them repair it. Run
validation, inspect output together, and pause. After readiness, generate and help
them find the new code and its dependencies. Activity: explain one YAML-to-Python
connection and why this is not evidence of a deployed pipeline. Save each substep.

## 8.4 — Choose a continuation

Recap actual activities and unresolved questions without claiming mastery. Offer
two or three relevant topics from [the directory](../topics/index.md); accept any
feature they name. They can finish, return to a deferred deployment, or take a
topic lesson. Record the selection and wait before its first checkpoint. If they
ask to switch to ordinary development, finish the teaching checkpoint, save progress
and use the development workflow without continuing learner exercises.
