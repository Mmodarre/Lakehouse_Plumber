# Topic — Optional LHP Web

Outcome: connect visual authoring to the same YAML/generation workflow. Read
[web authoring](../references/web-authoring.md). Offline archives omit the webapp
extra; the learner can finish the core course without it. Pause each checkpoint.

## web.1 — Check whether the interface is available

Explain graphs, action forms and validation/generation over the existing project.
Inspect installed capabilities and whether the browser can reach a local server.
Do not assume Databricks compute's localhost is the learner's laptop or invent a
proxy. If unavailable, explain the optional desktop path and offer to defer.
Pause for their choice; do not repeatedly attempt offline dependency downloads.

## web.2 — Open the same project

When requested and dependencies are available, use the installed version's webapp
extra and run `lhp web` from the learning project. Use its actual startup URL.
Activity: learner opens the project graph and locates the flowgroup already studied.
Pause; do not launch a second project or silently change configuration.

## web.3 — The learner edits a form

Ask them to change the same supported comment field used in Lesson 5 through the
form. They save it and inspect the underlying YAML. Activity: identify the field
that changed. You verify the saved file without doing the exercise for them. Pause.

## web.4 — Inspect generation

Let the learner run validation/generation from the UI, or run the equivalent CLI
on request. Compare the resulting Python with the source edit. Record actual
observations, stop any temporary server you started when the session is finished,
and offer a return to the course. Pause.
